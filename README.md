# rockpaperscissor
This is the simple command line game written in python.

HOW IT WORKS

there is a first_run flag, when the script is executed, it checks whether first_run.flag exists:
If the file does not exist, the program prints a welcome message and create the file.
On subsequent runs, the message will not appear again.

[This is one of the simple but unique logic which i have applied here which make the game more intresting whitout welcoming the user multiple time it only welcome one's and play it multiple times]

Then here in the game the user provide a choice (rock, paper, scissors).computer randomly select its own choice, and the winner is determined using basic rule comparison.
